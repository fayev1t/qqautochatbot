# 工具：`reflect`

## 功能

`reflect` 写下当前这一版自我认识。写入后，该文本作为一条 `<reflection>` 落在时间线
上，和群里发生的别的事一样按时刻排在流里。

**此前各版都还在。** 后写的一版不会抹掉先写的，只是更晚——往回翻就能看见这套
认识是怎么一步步变过来的：当时怎么想的、后来被什么推翻了、现在停在哪儿。

它是除任务之外第二个跨拍留存的装置，两者分工不同：任务承载**未竟之事**，
有 `complete` / `fail` 收束条件；反思承载**对自己的认识**，没有终点，逐版留痕。
不要用任务记录自我认识（它收束不掉），也不要用反思代替任务（它不提醒任何待办）。

本工具不发送消息、不改变群内任何状态，其他人看不到它写下的内容。

## 参数

- `text`：必填字符串，这一版自我认识的完整正文。去除首尾空白后不得为空，
  且不得超过 600 字。

写的时候当成**独立成篇的一段**：读它的人（下一拍的你）会连着前几版一起看到，
所以不必复述上一版仍然成立的部分，写清这一次想明白了什么、哪条判断改了即可。

## 返回

```json
{"written": true, "chars": 128}
```

## 失败

- `invalid_arguments`：`text` 缺失、非字符串、去空白后为空，或超过 600 字。
  超长**不会**被截断，整次调用失败——半截正文会在下一拍被当作完整想法读到。
  失败时 `reason_code` 取 `text_not_str` / `text_empty` / `text_too_long`。

## 调用限制

每段程序最多出现一个 `reflect` 调用点。

## 权限与作用域

无最低权限要求，所有 scope 可用。
