# 工具：`task`

## 功能

`task` 重写当前的待办便签。它只有一栏内容，整段覆盖——不是追加。

便签是给自己看的现状记录：**当前还有什么没办完**。要记两件事就在一段话里写
两件；办完了或本来就没事，传空串清空。

它没有编号、没有状态、没有条目切分，也不需要"结项"这一步——不用记了就删掉。

## 参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `content` | string | 新一版待办的完整正文。空串表示清空。上限 600 字。 |

超过 600 字直接调用失败，不会静默截断。

## 返回

`{"cleared": bool, "chars": int}`。`cleared` 为真表示这次调用清空了便签。

## 示例

```python
task(content="帮张三查明天上海的天气预报并在群内回复；另外李四让我下午三点提醒他开会")
```

办完之后清空：

```python
task(content="")
```

## 呈现方式

写下的内容折成信封顶部的 `<task>` 单栏，只显示最新一版，不出现在时间线上。
先前各版仍留在事件流里，但你看不到——便签只要现状。

需要留住"我是怎么想的、认识怎么变的"，用 `reflect`：那一条相反，逐版留在
时间线上，历史各版都在。
